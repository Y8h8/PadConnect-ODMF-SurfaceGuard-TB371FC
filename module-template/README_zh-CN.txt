PadConnect ODMF SurfaceGuard Magisk 模块 v1.0

适用设备：联想小新 Pad Pro 12.7 骁龙版 2023（TB371FC）
适用系统：第三方移植适配包 ColorOS 15.0.1.801_Final_A15_TB371FC[9044bd]
系统来源：由酷安用户“兰微卡鱼”提取、移植适配，原始发布平台为酷安

说明：该系统包不是联想、OPPO、OPlus 或 ColorOS 官方为 TB371FC 发布的系统。
感谢兰微卡鱼的移植与分享。本模块作者未参与该系统包的提取、移植或发布；双方
不存在合作、授权、代理或背书关系。

用途：修复跨屏镜像可以控制、但画面一直加载的问题。

安装：
1. 如果运行过任何 RAM 测试，先重启平板。
2. 在 Magisk/面具中选择“模块”→“从本地安装”。
3. 选择生成的模块 ZIP，安装完成后重启。

恢复：在 Magisk/面具中禁用或卸载本模块，然后重启。

警告：
- 不要与旧 Gralloc、allocator、composer、OMX、H264、YV12 或 ODMF RAM 补丁叠加。
- 系统更新前先禁用或卸载本模块。
- 模块只接受已验证的原始 ODMF SHA；系统文件变化时会自动禁用。
- 本模块仅供学习、研究和兼容性测试，刷入和使用风险由使用者自行承担。
- 本模块与联想、OPPO、OPlus、ColorOS、酷安及兰微卡鱼均无隶属或背书关系。
